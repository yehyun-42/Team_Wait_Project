# 주제: 유기동물 보호소 관제 시스템
**Stray Animal Shelter Monitoring System**
<br />

DW아카데미 AIoT 기반 드론 관제 시스템 개발 4회차 3팀 팀프로젝트
<br />

**목적**
<br />
- 보호 중인 유기동물의 탈출 및 사고 골든타임 확보를 위한 실시간 사고 감지 및 사후 처리
- 인적 한계 극복 및 사각지대 해소
- 유기동물 관리의 정확성 및 이상객체(야생동물 등) 침입 방지를 위한 다채널 전파
- 지속 가능한 보호소 운영을 위한 행정 효율화

**팀원 구성:** 5명
<br />

**데이터 흐름**
<br />
기준치 웹 대시보드 → 감지 기준치 DB → 기준치 딕셔너리 → YOLO(기준치 기반 감지) → 감지 내역 DB → 감지내역 웹 대시보드
<br />

**사용 기술**
<br />
| 구분 | 기술 스택 |
| :--- | :--- |
| **Language** | Python |
| **Framework** | Flask, SQLAlchemy |
| **AI / Video** | YOLO, OpenCV |
